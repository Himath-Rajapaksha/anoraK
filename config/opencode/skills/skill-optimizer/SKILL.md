# Skill Optimizer

## When to Use This Skill
- Identifying repeated workflows that could become skills
- Auditing existing skills for quality and guideline compliance
- Generalizing personal skills for public release
- Improving skill descriptions and trigger patterns

## Workflow
1. Review recent coding sessions for repeated patterns
2. Extract the workflow: what steps are repeated, what triggers them
3. Draft a skill: name, description, when-to-use, workflow, and rules
4. Validate against the guideline: minimal frontmatter, proper body structure
5. Test the skill: does it produce the expected behavior
6. Refine: improve the description, workflow steps, and rules
7. Publish: add to the skill collection and verify it works

## Rules
- Only extract workflows that repeat 3+ times
- Keep skills focused on one coherent workflow
- Follow the guideline strictly: minimal frontmatter, proper body structure
- Test skills before publishing — don't ship untested instructions
- Write for the general case, not your specific project
- Review and update skills as the workflow evolves

# Epic Planning

## When to Use This Skill
- Breaking a large feature into manageable stories
- Estimating effort and identifying dependencies
- Creating an implementation plan with milestones
- Tracking progress against the plan

## Workflow
1. Define the epic: what the feature accomplishes and why it matters
2. Break into stories: each story should be independently deliverable
3. Estimate stories: use story points or time estimates
4. Identify dependencies: which stories block others
5. Order stories: deliver dependencies first, then build on them
6. Define milestones: group stories into deliverable increments
7. Create the implementation plan: timeline, owners, and checkpoints
8. Track progress: update story status and adjust the plan as needed

## Rules
- Each story should be completable in one sprint or less
- Don't skip dependency identification — it causes surprises later
- Estimate before ordering — don't assume which stories are small
- Define acceptance criteria for every story
- Review the plan with the team before committing to it
- Adjust the plan when new information emerges — don't follow a stale plan

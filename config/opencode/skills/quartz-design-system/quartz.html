Quartz · shadcn/ui × Vercel × Apple · v1.0.0

A monochrome theme with
shadcn bones.

shadcn/ui's token architecture — --background, --primary, --radius — skinned in pure neutrals, Geist display type at -0.03em, Geist Mono for data, stock component geometry, and a fifth of Apple: frosted material, layered depth, springy motion.

01 — Colour roles

Semantic tokens, neutral values.

Every shadcn role, mapped to a measured neutral value. Chips read live from CSS — they change with the theme.

No brand hue exists in Quartz — contrast is carried by black/white blocks and type scale. --destructive keeps shadcn's system red; charts use a greyscale ramp derived from the neutrals.

02 — Typography

Roman heading, italic emphasis.

Geist carries structure at weight 400 — never bold. Geist Mono is reserved for data: meta rows, indices, stat labels.

03 — Shape & motion

Frosted glass, soft corners.

--radius: 0.625rem is the control radius (10) for buttons and inputs; --radius-card (18) gives Apple-scale corners to cards and sheets; --radius-block (32) is the Quartz holdout; the pill survives on badges and chips only. Checkbox keeps 6.

Motion

250ms on --ease (0.32, 0.72, 0, 1) — Apple's deceleration. Hover springs on --ease-spring (0.34, 1.4, 0.64, 1) with a 1px lift; release falls back to the calm curve. Nothing bounces twice.
